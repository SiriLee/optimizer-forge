## 1　引言

作业要求是“针对梯度类方法，在 AI 辅助下设计一个新的梯度类方法，并通过实验验证其有效性”，交付物可以是 skill、skill set 或 harness 工程，报告要讲清“思考逻辑”。

课堂板书写得很清楚，它其实是教材 §3.4 的四层结构：① 只用 $\nabla f$ 就是一阶方法，用 $\nabla^2 f$ 才是二阶；② 方向 $d$ 必须满足 $\nabla f(x)^\top d<0$；③ 步长 $\alpha$ 必须让 $f$ 下降；④ 理论框架是“收缩 + 充分下降”两条不等式，并追问“怎么选”。板书下半块则给了交付形态的提示：`实际问题系列 → AI + harness 工程 → verify`，旁边写着 token 消耗与 recursive self-improvement。

因此本文的判断是：这份作业考的不是“发明一个花哨算法”，而是**能否把设计空间说清楚、把验证做得诚实、并把 AI 的参与留下可复现的痕迹**。据此，本文的贡献有三点：

1. **设计空间**：把梯度类方法分解为 7 个维度（预条件结构、曲率估计、区间规则、步长、加速、保护、噪声处理），使“设计”变成在空间中选点，而不是碰运气。
2. **方法 AIPG**：把对角预条件从“估一个点”改成“估一个区间”，于是步长选择成为一个有闭式解的最小最大问题；在理想情形（区间为真括号、不带动量）下给出逐点收缩上界，实用配置里这一保证退化为单调性（§5.5 如实报告）。
3. **设计循环**：Optimizer Forge 用静态闸、理论闸、实验闸三级过滤候选，12 轮中 6 个候选被真实否决（其中 3 个是语义性否决而非语法错误），全过程可离线重放。

## 2　设计空间

### 2.1　教材框架下的“加一行”

教材表 3.1 把梯度类方法写成

$$x^{k+1}=x^{k}-\alpha_k d^{k},\qquad \nabla f(x^{k})^{\top}d^{k}>0$$

并通过选择 $d^k$ 得到 GD（$-g$）、牛顿法（$-H^{-1}g$）、scaling GD（$-Dg$）、对角 scaling GD 等。所谓“设计一个新方法”，在这个框架下就是**给表 3.1 加一行**，并回答三件事：这一行的 $d^k$ 用什么信息、$\alpha_k$ 怎么选、它在 ④ 的两条不等式下满足什么。

本文加的这一行是

$$x^{k+1}=x^{k}-D_k g_k,\qquad D_k=\mathrm{diag}\!\left(\frac{2}{u_i^{k}+\ell_i^{k}}\right)_{i=1}^{n}$$

其中的 $[\ell_i^k,u_i^k]$ 是第 $i$ 个坐标的曲率**区间**。与表 3.1 已有的行相比，区别在于：对角 scaling 需要事先知道（或估计）一个矩阵，而我们估计的是一个带不确定性的区间，并把不确定性直接编码进步长。

### 2.2　七个设计维度

| 维度 | 可选值 | 本文选择 |
|---|---|---|
| D1 预条件结构 | $I$ / 对角 / 对角+全局标量 / 对角+低秩 | 对角 |
| D2 曲率估计 | 坐标差分 secant / 梯度范数比 / EMA | 坐标差分 secant |
| D3 区间规则 | 固定全局 $[\mu,L]$ / 滑动窗口 min-max / 收缩到 secant | 窗口 20 + EMA 0.2 |
| D4 步长 | $2/(u+\ell)$ / $1/u$ / BB1 / BB2 / 线搜索 | $2/(u+\ell)$ |
| D5 加速 | 无 / 三项 Chebyshev / Nesterov / 重启 | 三项 Chebyshev |
| D6 保护 | 无 / 单调检查 / Armijo | Armijo（$c=10^{-4}$） |
| D7 噪声处理 | 无 / 小批量梯度 EMA / 区间放大 | 无（本文只用全梯度） |

这张表就是第 6 节设计循环的动作空间：候选方法被写成这 7 个维度的取值，因此可以被机器校验、被日志记录、被离线重放。

### 2.3　两个结构量：尺度差异与耦合度

本文的经验结论围绕两个可测的量展开。第一个是对角跨度

$$\mathrm{spread}(H)=\frac{\max_i H_{ii}}{\min_i H_{ii}}$$

它度量各坐标的曲率尺度差多少。对角预条件的本质是“每个坐标除以自己的 $H_{ii}$”；如果各坐标尺度相近（$\mathrm{spread}\approx1$），对角阵近似为标量阵，等价于选了个好的 GD 步长，不会带来结构性收益。第二是非对角耦合度

$$\mathrm{coupling}(H)=\frac{\|H-\mathrm{diag}(H)\|_F}{\|H\|_F}$$

它度量“逐坐标估计被其他坐标污染的程度”，决定尺度差异带来的潜力能兑现多少。

两者分工不同：**spread 决定“有没有可利用的结构”，coupling 决定“利用得多干净”**。第 5.3 节的数据会把这两个量分开看，而不是用一个量硬套所有现象。两个量都能在实验之前算出（对二次问题与最小二乘精确，对逻辑回归用 Gauss–Newton 矩阵），因此属于事前可检验的假设，不是事后解释。

## 3　方法

### 3.1　曲率区间

每一步我们只用点与梯度（因此仍是一阶方法）。设第 $k$ 步的位移与梯度差为 $\Delta x=x^{k}-x^{k-1}$、$\Delta g=g^{k}-g^{k-1}$，则坐标 secant 为

$$\tilde h_i^{k}=\frac{\Delta g_i}{\Delta x_i},\qquad |\Delta x_i|>\tau_i$$

对二次问题它精确等于 $H_{ii}$；对一般问题它是由中值定理给出的平均曲率。把最近 $w$ 个有效 secant 取 min-max 得到 $[\ell_i,u_i]$，再与上一轮的区间做 EMA 平滑，并截断到 $[\mu_0,\hat L]$（$\hat L$ 为全局光滑常数，所有方法共用）。窗口与 EMA 是设计维度 D3，它们控制“多快相信新观测”。

### 3.2　步长：一个最小最大问题

给定区间 $[\ell_i,u_i]$，我们希望步长对区间内任何真实曲率都不至于太糟，于是解

$$\alpha_i^{\star}=\arg\min_{\alpha}\ \max\bigl\{|1-\alpha\ell_i|,\ |1-\alpha u_i|\bigr\}$$

**命题 1**　上式的最优解为 $\alpha_i^\star=2/(u_i+\ell_i)$，最优值为 $(u_i-\ell_i)/(u_i+\ell_i)$。

这个闭式解正是板书第 ④ 条“怎么选”的一个直接回答：**不是选一个点估计的倒数，而是选对区间最不敏感的步长**。当区间退化为一点（$\ell=u=h$）时 $\alpha=1/h$，退化为坐标牛顿；当区间取全局 $[\mu,L]$ 时退化为经典 GD 的界。所以 AIPG 是“GD ↔ 坐标牛顿”之间的连续插值，插值参数是我们对曲率的了解程度。

### 3.3　加速与保护

仅靠逐坐标步长，收敛速度受条件数限制。我们叠加 Chebyshev 三项递推：把 $\alpha_i$ 换成

$$\alpha_i=\frac{4}{(\sqrt{u_i}+\sqrt{\ell_i})^{2}},\qquad \beta_i=\left(\frac{\sqrt{u_i}-\sqrt{\ell_i}}{\sqrt{u_i}+\sqrt{\ell_i}}\right)^{2}$$

并令 $d=\beta\odot(x^{k}-x^{k-1})-\alpha\odot g_k$。当区间紧时 $\beta_i\to 0$，退化为 3.2 的步长；当区间宽时 $\beta_i$ 接近 1，给出近似最优的加速。$\beta$ 被截断在 0.9 以内以防振荡。

保护采用 Armijo 回溯：若 $f(x^{k}+t\,d)>f(x^{k})-c\,t\,(-g_k^{\top}d)$ 就把 $t$ 减半。若 25 次仍不接受，则回退到 $x^{k}-g_k/\hat L$ 并记一次 fallback。

### 3.4　算法

```
输入: x0, 初始区间 [mu0, Lhat], 窗口 w, EMA beta, c
g = grad(x0);  ell = mu0*1;  u = Lhat*1
for k = 0,1,2,...:
    alpha = 2/(u+ell)                      # 命题 1
    d = beta*(x - x_prev) - alpha*g        # Chebyshev 三项
    t = 1
    while f(x + t*d) > f(x) - c*t*(-g^T d): t /= 2   # Armijo
    x_new = x + t*d;  g_new = grad(x_new)
    h = (g_new - g)/(x_new - x)            # 坐标 secant（仅用一阶信息）
    [ell, u] = window_minmax(h) 经 EMA 与截断
    x_prev, x, g = x, x_new, g_new
```

### 3.5　与既有方法的关系

| 维度 | 对角 BFGS/SR1 | Adam | BB | **AIPG** |
|---|---|---|---|---|
| 曲率来源 | 拟牛顿方程（全向量） | 梯度二阶矩 | 单步 secant（标量） | 坐标 secant → **区间** |
| 步长 | 线搜索 | 自适应衰减 | 两种闭式 | **最小最大闭式** |
| 每步保证 | 需 Wolfe 条件 | 无 | 无 | **理想情形收缩界 + Armijo 单调** |
| 可输出诊断 | 无 | 无 | 无 | **$\hat\rho_k$、区间宽度、Armijo 折半次数** |

我们不声称这是文献首创：坐标 secant、Chebyshev 半迭代、Jacobi 预条件都是经典工具。本文主张的新意在于**把“估计”改成“估计 + 区间”，从而使步长成为一个有闭式最优解的最小最大问题，并在理想情形下给出每步可核对的收缩上界（实用配置的落差见 5.5 节）**。

### 3.6　复杂度

每步一次梯度、一次 secant 更新（$O(n)$）与常数次函数求值（Armijo 平均 1.2 次）。内存 $O(nw)$。与 GD 同阶，比 L-BFGS（$O(nm)$ 且需线搜索）更省。

## 4　理论分析

### 4.1　假设

**A1**（光滑）$f$ 是 $L$-光滑的，$\hat L\ge L$ 是可用估计。**A2**（对角结构）$H(x)=\mathrm{diag}(h(x))$，$h_i(x)\in[\ell_i,u_i]$。A2 是定理 1 成立的**前提**；第 4.6 节讨论它被违反时会发生什么。

### 4.2　命题 1（最小最大步长）

记 $\phi(\alpha)=\max\{|1-\alpha\ell|,|1-\alpha u|\}$。由于 $|1-\alpha h|$ 关于 $h$ 是凸的，最大值在端点取到，故 $\phi(\alpha)=\max\{|1-\alpha\ell|,|1-\alpha u|\}$。令两端相等得 $\alpha=2/(u+\ell)$，此时 $\phi=(u-\ell)/(u+\ell)$。任何其他 $\alpha$ 都会使某一端更大，故最优。∎

### 4.3　定理 1（对角二次的收缩）

在 A2 且 $f$ 为二次时，逐坐标有

$$|x_i^{k+1}-x_i^{\star}|\le \rho_i\,|x_i^{k}-x_i^{\star}|,\qquad \rho_i=\frac{\kappa_i-1}{\kappa_i+1},\ \ \kappa_i=\frac{u_i}{\ell_i}$$

带 Chebyshev 加速时 $\rho_i=(\sqrt{\kappa_i}-1)/(\sqrt{\kappa_i}+1)$。特别地，当 $\ell_i=u_i=h_i$ 时 $\rho_i=0$，即坐标一步收敛；当区间取全局 $[\mu,\hat L]$ 时退化为 GD 的经典界 $(\kappa-1)/(\kappa+1)$。

*证明*：单个坐标上是标量二次 $f_i=\frac{1}{2} h_i x_i^2-b_ix_i$，梯度步给出 $x_i^{+}-x_i^\star=(1-\alpha_i h_i)(x_i-x_i^\star)$，由命题 1 即得。Chebyshev 情形是标准三项递推的收缩估计（例如 Golub & Van Loan 的 Chebyshev 半迭代），把 $\alpha,\beta$ 代入特征多项式即可。∎

### 4.4　定理 2（一般凸：单调下降与 O(1/√K)）

设 A1 成立，且每步由 Armijo 接受。由于 $u_i\le\hat L$ 且 $\alpha_i=2/(u_i+\ell_i)\ge 1/u_i\ge 1/\hat L$，有

$$-g_k^{\top}D_kg_k=\sum_i\alpha_i g_{k,i}^{2}\ \ge\ \frac{1}{\hat L}\|g_k\|^{2}$$

Armijo 条件给出 $f(x^{k+1})\le f(x^{k})-c\,(-g_k^{\top}D_kg_k)\le f(x^{k})-\frac{c}{\hat L}\|g_k\|^{2}$，故 $f$ 单调下降，且

$$\sum_{k=0}^{K-1}\|g_k\|^{2}\ \le\ \frac{\hat L}{c}\bigl(f(x^{0})-f^{\star}\bigr)$$

若 $f$ 凸、$\|x^{k}-x^{\star}\|\le D$，则 $f(x^{k})-f^{\star}\le D\|g_k\|$，代入得

$$\min_{k<K}\bigl(f(x^{k})-f^{\star}\bigr)^{2}\ \le\ \frac{D^{2}\hat L}{cK}\bigl(f(x^{0})-f^{\star}\bigr)$$

由单调性，左端就是末次迭代的间隙，于是 $f(x^{K})-f^{\star}=O(1/\sqrt K)$。

**为什么不是 $O(1/K)$。** $O(1/K)$ 的标准证明要用二次上界引理 $f(x^{+})\le f^{\star}+\frac{1}{2\alpha}\|x-x^{\star}\|^{2}-\frac{1}{2\alpha}\|x^{+}-x^{\star}\|^{2}$，它要求 $\alpha\le 1/L$。而区间收紧后 $\alpha_i\approx1/h_i$ 可以远大于 $1/\hat L$（这正是方法快的原因），所以那条路走不通，只能得到 $1/\sqrt K$。把步长换成固定的全局区间（`fixed` 变体，步长 $2/(\hat L+\mu_0)$，量级上等价于标准 GD 步长）可以恢复 $O(1/K)$——它在 P1 上要 4379 次，而完整版只要 44 次。**这是“可证速率”与“实际速度”的取舍，不是证明的疏漏。**

### 4.5　定理 3（强凸：线性收敛）

若 $f$ 还是 $\mu$-强凸，则由 $\|g_k\|^{2}\ge 2\mu\,(f_k-f^\star)$ 得

$$f(x^{K})-f^{\star}\ \le\ \left(1-\frac{2c\mu}{\hat L}\right)^{K}\bigl(f(x^{0})-f^{\star}\bigr)$$

注意常数 $2c\mu/\hat L$ 很小（$c=10^{-4}$），这个界非常保守——它只说明“不会不收敛”，实际速率由第 5 节的实验给出。这是诚实的分工：定理负责安全性，区间结构负责速度。

### 4.6　耦合时会发生什么

A2 被违反时，上述证明全部失效。更糟的是，**对角预条件本身就可能是发散的**。定义

$$\tilde H=D^{1/2}HD^{1/2}$$

$$\rho_{\mathrm{exact}}=\max_i|1-\lambda_i(\tilde H)|$$

它是以真实对角 $D=\mathrm{diag}(1/H_{ii})$ 做预条件时的一步收缩因子。我们在 5 个问题上算了它，并做了一个“oracle 实验”：直接给方法真实对角曲率、不做任何保护，跑 300 步。

| 问题 | coupling | $\rho_{\mathrm{exact}}$ | oracle 300 步后的 $f-f^\star$ |
|---|---|---|---|
| P1 对角二次 | 0.00 | $3\times10^{-16}$ | $-1.8\times10^{-15}$（收敛） |
| P4 逻辑回归 | 0.10 | 0.35 | $-5.6\times10^{-17}$（收敛） |
| P3 i.i.d. 最小二乘 | 0.26 | 1.34 | $4.5\times10^{+73}$（发散） |
| P2 旋转二次 | 0.84 | 5.61 | $\infty$（发散） |
| P3 Toeplitz 最小二乘 | 0.94 | 16.2 | $\infty$（发散） |

这个实验说明了两件事：第一，**AIPG 的优势边界不是估计误差造成的**，而是对角近似的结构性限制；第二，AIPG 在 P3（i.i.d.）上仍然能 111 步收敛，靠的正是“区间未收缩时的保守步长 + Armijo 保护”，也就是说保护不是装饰，而是让方法在越界时退化成安全的（慢的）GD。

唯一的明显失败是 P2（旋转二次）：AIPG 1084 次，慢于 Heavy-ball（202）与 NAG（369）。下一节说明它不是“耦合度高”那么简单。

### 5.3　两个结构量的分工

{{TABLE:structure}}

<figure>{{FIG:f6_structure}}<figcaption>图 2　相对 NAG 的加速比 vs 非对角耦合度，点旁标注为对角跨度。P3（Toeplitz）因 NAG 未收敛而以空心三角标出，其纵坐标是下界（40001/5993 ≈ 6.7）。</figcaption></figure>

这张图推翻了我们最初“耦合度越高越差”的假设，也是本文最值得写下来的一处自我修正：

- **P3（Toeplitz）的 coupling = 0.94，却仍然最快。** 如果按 coupling 划界，它应当和 P2 一样失败。它没有失败，因为它的对角跨度是 $10^4$：即便逐坐标估计被相关性污染，把所有坐标拉到同一尺度这件事本身就已经带来巨大收益。
- **P2 的 coupling = 0.84，但真正的问题是跨度只有 2.1。** 旋转把曲率均匀摊到所有坐标上，对角预条件近似标量，等于退化成 GD；此时保护只能保证不发散，不能带来速度。

所以正确的说法是：**spread 是必要条件，coupling 是效率因子**。跨度大时，对角预条件通常有可利用的潜力；耦合度高则会让兑现程度打折：P3 Toeplitz 的绝对次数比 P3 i.i.d. 多 54 倍（5993 vs 111），但两者 κ 也相差约 1000 倍；换成对 NAG 的加速比看，coupling 造成的折扣约 1.5–1.7 倍（11.1× vs ≥6.7×，比值 1.66）。跨度接近 1 时，无论耦合度多少，方法都退化为 GD 级别（P2）。这解释了主表里所有 6 个结果，而不需要为 P3c 开特例。

### 5.4　消融（单变量）

{{TABLE:ablation}}

四个配置只差一个维度，全部继承胜者的预条件（窗口 20 / EMA 0.2），因此是真正的单变量对比。

**去动量**：P1 上几乎无影响（44 vs 45），因为区间收紧后 $\beta_i\to0$，动量自动失效；但在 P2 慢 3.7 倍（1084 vs 3990）、P5 慢 4.9 倍（2578 vs 12702）、P3 Toeplitz 慢 5 倍（5993 vs 30278）。**动量的价值在耦合与非凸情形，不在对角情形**——这与 3.3 节的动机一致。

**全局标量**（把逐坐标区间替换成一个标量）：P1 从 44 退到 15894，P3 i.i.d. 从 111 退到 30083，P3 Toeplitz 直接不收敛。收益的主体来自“逐坐标”，而不是“自适应步长”本身。

**固定区间**（不做区间学习，始终用全局 $[\mu,\hat L]$）：P1 从 44 退到 4379，说明学习区间确实在起作用；但它在 P2 上反而更好（495 vs 1084）。这印证了 5.3 节的判断：**在跨度小的问题上，保守的全局步长比激进的逐坐标步长更合适**。

### 5.5　收缩证书的适用范围（一个负结果）

命题 1 是恒成立的（步长由构造给出）。但**定理 1 的逐点收缩界只在理想条件下成立**：区间必须是真的括号（$h_i\in[\ell_i,u_i]$），且不带动量。报告采用的胜者配置做了两件破坏这个前提的事——EMA 平滑（区间不再保证是括号）与 Chebyshev 动量（逐步比值可短暂超过 1）——所以我们**不能**声称“每一步的收敛都可核对”。

<figure>{{FIG:f2_certificate}}<figcaption>图 3　P1 上理论界 $\hat\rho_k$ 与实测 5 步平均收缩。实测全程高于理论界（中位数 1.26 倍，最大 2.31 倍）。这张图的作用是否定“逐点证书”，而不是展示它。</figcaption></figure>

数值上：胜者配置在 P1 的 39 个 5 步窗口**全部**高于理论界（其中 29 个超过 1.1 倍），比值中位数 1.26、最大 2.31（0.25 vs 0.108）；单步比值最高到 208（动量瞬态）。也就是说，**在实用配置下只剩定理 2 的单调性，逐点证书失效**。

这不是实现错误，而是设计取舍的直接后果。只去掉动量（仍用 EMA 0.2，即 `aipg_plain`）并不会恢复证书，只会让 P3 Toeplitz 从 5993 退化到 30278；把 EMA 调到 1.0、让区间成为真括号后，P1 确实两步就到机器精度、定理 1 成立，但那样的配置（第 2 轮）在 P2 上被 R5 判为失效（界为 0 而实测 0.998），因此没有进入全量评测。**我们选择速度，并如实报告失去的保证。** 校验脚本里的 R5 因此只作为“爆炸检测”（实测不超过界的 10 倍加 0.05 绝对余量），不作为证书。

### 5.6　失败案例

P2 上 AIPG 的 1084 次调用里，**fallback 一次也没有触发**（日志中 `fallbacks=0`），Armijo 只做了少量折半：函数求值 / 梯度求值 = 1.12，即约 12% 的额外函数求值。这与“保护频繁生效”的直觉不同——保护是安全网，不是主要开销来源。

P5 上 GD、Heavy-ball、BB1 在 $2\times10^4$ 次内完全无法收敛；AIPG 靠动量与保护把间隙压到 $10^{-10}$ 量级，但速度远不及利用二阶信息的 L-BFGS（44 次）。这两处不粉饰：**AIPG 不是通用加速器**。

## 6　AI 辅助的设计循环

### 6.1　流水线

```
Brief ──► Propose ──► 静态闸 ──► 理论闸 ──► 实验闸 ──► Record
        (LLM/网格)   DSL 合法性   不变量检查   冒烟→全量    日志/排名
```

- **静态闸**：DSL 取值域、类型、以及“无保护时不允许动量”这类结构性规则。
- **理论闸**：在两个探针上跑 120 步，检查 R1 正定、R2 下降方向、R3 保护生效、R4 单调、R5 收缩比未爆炸、R6 数值健康。探针故意选一个对角问题和一个耦合问题，避免只在有利情形上校验。
- **实验闸**：2 种子冒烟 → 前 4 名 → 3 种子全量 → 按跨问题归一化分数排序，5% 以内按“更早提出者优先”（Occam 规则）。

### 6.2　候选的表示

候选是纯数据，例如胜者：

```json
{"precond": {"type": "diag", "window": 20, "ema": 0.2, "adaptive": true},
 "step":    {"rule": "minimax"},
 "accel":   {"type": "chebyshev", "beta_cap": 0.9},
 "safeguard": {"type": "armijo", "c": 1e-4, "halvings": 25}}
```

因为候选是数据，闸门可以先于运行否决它，日志也可以离线重放（`--proposer recorded`，不需要 API key）。

### 6.3　十二轮记录

{{TABLE:rounds}}

12 个候选中有 5 个被闸门直接否决（3 个静态、2 个语义性），其余 7 个进入实验闸：6 个落选、1 个胜出。两次语义性否决值得单独说；另有一组「闸门通过、实验淘汰」的对照：

- 第 2 轮（窗口 1、EMA 1.0）：区间退化成点估计，候选自报 $\hat\rho=0$，实测却是 0.998——**过度自信的区间让界失效**。
- 第 4 轮（全局标量）是一组「闸门通过、实验淘汰」的对照：它用逐坐标区间算界、却用标量步长，R5 放宽到 10 倍后不再拦它；冒烟阶段它以 21934 的分数垫底出局——闸门只是必要条件，不代替评测。
- 第 6 轮（无保护 + $1/u$ 步长）：在 P2 上 $f$ 直接上升（−10.99 → −10.47），R4 与 R5 同时报错。这是“无保护”在耦合问题上的真实代价。

**必须披露的选择偏差**：实验闸与最终主表用的是同一套 6 个问题，因此主表数字是在“被选中的同一批问题”上测的，偏乐观。三个独立的缓解证据是：① 消融里的 w1/w5/w50 与 w20 在同一条曲线上（`design_log/rounds.jsonl`）；② 被选的 w20/ema0.2 在 P2 上并非最优（495 属于固定区间变体），说明它没有专门为 P2 调过；③ 基线的调参预算更少（Adam 固定 lr=0.01），这一项对 AIPG 有利，读表时应打折。更严格的做法是留出问题做测试集，本文没有做到，如实写在这里。

## 7　讨论与局限

1. **A2 是硬约束**。所有定理都建立在“坐标近似解耦”上；5.5 节的负结果说明实用配置下连逐点证书都保不住，只剩单调性。改进方向是加低秩修正（对角 + rank-1 SR1），这是明确但未完成的后续工作。
2. **理论界很松**。定理 2 只给 $O(1/\sqrt K)$，常数含 $c=10^{-4}$，它保证“收敛”，不解释速度；速度由 spread 与 coupling 共同决定。
3. **收益依赖尺度差异**。这是本文最重要的边界：跨度接近 1 时（P2）方法退化为 GD 级别。机器学习里“未标准化特征”很常见，但标准化之后这个方法就没有优势——这一点必须写清楚，否则会被误用。
4. **选择集 = 测试集**。见 6.3 的披露；这是本文实验设计上最弱的一环。
5. **实验规模有限**。维度 100–200，未涉及深度学习规模；P5 只有 2 维，非凸结论只具示意性。
6. **“AI 辅助”的边界**。候选由作者与模型共同整理后写入 `proposals.jsonl`，搜索与闸门是离线重放的；报告标题里的“设计循环”指的是这个可重放的流程，不是“模型自主发现了方法”。12 轮里 6 轮被否决，说明闸门在管事，也说明提议质量参差。

## 8　结论

本文按教材 §3.4 的框架给表 3.1 加了一行：把对角预条件从“点估计”改为“区间估计”，步长取区间上的最小最大最优解，并叠加 Chebyshev 加速与 Armijo 保护。理论上给出了最小最大最优性、对角二次的收缩、一般凸的单调下降与 $O(1/\sqrt K)$、强凸的线性收敛；实验上在 4/6 个问题上优于全部一阶基线（对角二次上为 NAG 的 1/26），并把收益与失效分别归因于两个可测的结构量：**对角跨度决定有没有收益，耦合度决定收益打几折**。

我们也留下了两个诚实的负结果：实用配置下逐点收缩证书失效（5.5 节），以及即使拿到真实对角曲率、耦合问题仍会发散（4.6 节）。这两条比“又快了多少倍”更能说明方法的边界在哪里。

如果要给这份作业留一句话：**一个好的梯度类方法不该只在某个问题上快，而应该能说清自己在什么结构上快、为什么快、以及为此放弃了什么保证。** AIPG 做到了前两点，第三点靠删掉一个漂亮但站不住的结论来做到；低秩修正与留出集验证是下一步。

## 附录 A　证明细节

**命题 1**：见 4.2。**定理 1**：见 4.3。**定理 2**：由 $u_i\le\hat L$ 得 $\alpha_i\ge1/u_i\ge1/\hat L$，故 $-g^{\top}Dg\ge\|g\|^{2}/\hat L$；Armijo 给出每步下降至少 $c\|g_k\|^{2}/\hat L$，求和得 $\sum_k\|g_k\|^{2}\le(\hat L/c)(f_0-f^{\star})$；凸性给出 $f_k-f^{\star}\le D\|g_k\|$（$D=\|x^{0}-x^{\star}\|$，需要迭代点保持在球内，这一点在凸情形下由 $\|x^{k}-x^{\star}\|\le\|x^{0}-x^{\star}\|$ 不能自动保证，故该速率是**条件性**的：在 $f$ 的次水平集有界时成立，或等价地取 $D$ 为次水平集的半径）。**定理 3**：$\|g\|^{2}\ge2\mu(f-f^{\star})$ 代入每步下降即得 $(1-2c\mu/\hat L)^{K}$。
