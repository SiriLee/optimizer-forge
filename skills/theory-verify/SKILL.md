# 理论校验

两个层次：**静态闸**只看 DSL，**理论闸**要在探针问题上真跑。

## 静态闸（`forge.dsl.validate`）

- 取值域、类型、数值范围（窗口 1–50、EMA 0–1 等）。
- R3 静态部分：没有 safeguard 时不允许动量，且步长必须用 `1/u`（保证 $\alpha\le 2/L$ 的前提）。
- 任何一条不满足，直接拒绝，不进入运行。

## 理论闸（`forge.verify.check_dynamic`）

在 120 步探针上检查：

| 规则 | 含义 |
|---|---|
| R1 | 预条件矩阵正定（$\alpha_i>0$ 且有限） |
| R2 | 下降方向（$-g^\top Dg>0$） |
| R3 | 保护生效（fallback 次数被记录，不算失败） |
| R4 | 目标函数单调不增 |
| R5 | 爆炸检测：经验收缩不超过 `10 × 理论界 + 0.05`（0.05 是绝对余量，防止"界为 0"时误判）（**不是**逐点证书；实用配置下 5 步平均常高于界，见报告 5.5） |
| R6 | 无 NaN/Inf |

**探针必须至少两个**：一个对角问题（证书应当成立），一个耦合问题（证书不应当说谎）。只在对角问题上校验会放过"在耦合问题上夸大保证"的候选。

## 判据

- 全部通过 → 允许进入实验闸。
- 任一失败 → 记录 `{规则: 具体数值}`，该候选只能出现在报告的"被否决候选"表里。
- 不要把"跑得慢"当成理论失败；速度由实验闸负责，理论闸只管**声称的保证是否成立**。

## 常见否决及含义

| 现象 | 诊断 |
|---|---|
| R5 经验收缩远大于理论界（如 436 vs 0.99） | 无保护 + 强耦合，方法已经发散 |
| R5 界为 0 但经验为 0.998 | 区间退化成点估计（EMA=1.0、窗口 1），过度自信 |
| R4 目标函数上升 | 步长越过 $2/L$ 且无保护 |
